# Research collaboration instructions

The authorized public repository is zja42/econ490-father-leave, branch main. Preserve commit history and verify GitHub synchronization after authorized revisions.

The current study is the OECD-only employment gender gap panel. Use paid father-specific leave weeks, wage replacement and its interaction with weeks, and the controls described in the README. Retain the existing Stata panel estimation and export sequence. Keep the do-file free of comments and build the analysis panel from the supplied source inputs inside Stata.

Keep input files in data/ and checked output in results/. Keep machine-specific paths and Stata license details out of published output.
